# 新手教程：从零把网站装起来

> 写给**不懂技术**的老师和产品经理。照着做大约 30 分钟，全程只用浏览器，不用在电脑上装任何软件。
> 下面以阿里云为例，腾讯云也大同小异。
>
> 遇到看不懂的提示，把屏幕截图发给任何一个 AI 助手，问它"下一步点哪里"，基本都能解决。

## 总共 6 步

| 步骤 | 做什么 | 花费 |
|---|---|---|
| 1 | 买一台云服务器 | 约 99 元/年 |
| 2 | 设置密码、打开网页端口 | 免费 |
| 3 | 连上服务器，上传安装包 | 免费 |
| 4 | 运行一行安装命令 | 免费 |
| 5 | 申请大模型 API Key，填到服务器上 | 按用量付费，一个班一次大约几毛到一两块 |
| 6 | 注册管理员账号，发邀请码给老师 | 免费 |

> 只想先看看效果？做完前 4 步就能用"演示模式"：不需要 API Key，上传 Excel 成绩表也能生成报告，只是报告里的文字由模板生成。

---

## 第 1 步：买服务器

在阿里云购买"云服务器 ECS"，按下面这样选：

| 选项 | 选什么 |
|---|---|
| 实例 | **2 核 2G** 就够了，比如 e 实例 |
| 地域 | 离你近的，比如"华东2（上海）" |
| 镜像 | 点"操作系统"，选 **Ubuntu**，版本选 **24.04 64位**（不要选 Windows） |
| 系统盘、网络 | 保持默认 |
| 带宽 | 按固定带宽，3 Mbps |

付款后，等 1～5 分钟，服务器状态变成"**运行中**"就开通好了。

## 第 2 步：设置密码、打开网页端口

1. 进入控制台 → 云服务器 ECS → 实例（左上角的地域要选对），找到你的服务器。
2. 点"**重置密码**"，用户名是 `root`，设一个复杂的密码，**自己记好，不要发给任何人**。改完按提示重启。
3. 点"**网络与安全组**" → 安全组 → "**配置规则**" → 入方向 → "**手动添加**"：
   - 协议选"Web HTTP 流量访问"（也就是 80 端口）
   - 访问来源填 `0.0.0.0/0`
   - 点确定
4. 记下实例详情里的"**公网 IP**"，比如 `1.2.3.4`。

## 第 3 步：连上服务器，上传安装包

1. 从本仓库的 [Releases](../../../releases) 下载 `xueqing-release.zip`（**不要**下载绿色 Code 按钮里的源码包）。
2. 在实例页面点"**远程连接**" → "通过 Workbench 远程连接" → "立即登录"。
   - 第一次会弹出"服务关联角色"的提示，点"确定"。
   - 如果免密连接失败，就选"终端连接"，用 `root` 和第 2 步设的密码登录。
3. 登录后会出现一个黑色窗口。确认窗口上方选的是"**Shell**"，不是 Agent。
4. 点最左边的**文件夹图标**（文件管理），展开后找到 `root` 文件夹，**右键 → 上传文件**，选刚才下载的 `xueqing-release.zip`。

## 第 4 步：安装

在黑色窗口里粘贴下面这一整行，然后按回车：

```bash
apt-get update && apt-get install -y unzip && cd /root && unzip -o xueqing-release.zip && cd xueqing && bash deploy/install.sh
```

- 屏幕会滚动大量英文，这是正常的。大约 5～10 分钟，中途不用操作。
- 如果弹出紫色或蓝色的选择框，直接按回车。
- 屏幕上会出现一行"**已生成注册邀请码：xxxx**"，**把它记下来**，注册账号时要用。
- 最后看到"**安装完成。浏览器打开：http://你的IP**"，就装好了。

现在用浏览器打开 `http://你的公网IP`，就能看到网站首页。

## 第 5 步：申请大模型 API Key 并填到服务器上

API Key 相当于"调用 AI 的钥匙"，费用记在申请人自己的账户上。**不要把 Key 发给任何人，也不要贴到聊天里。**

### 推荐：阿里云百炼（通义千问）

能识别拍照的试卷和表格，用的是阿里云账号，不用另外注册。

1. 打开 [阿里云百炼控制台](https://bailian.console.aliyun.com/)，第一次进入要按提示开通服务。
2. 页面左上角的地域选"**华北2（北京）**"。
3. 进入"**API Key**"页面，点"**创建 API Key**"，然后**复制**这个 Key。
4. 同一个页面上方会显示 **Base URL**（以 `https://` 开头、以 `/compatible-mode/v1` 结尾），也复制下来。
5. 账户里充一点钱，几十元就够用很久。

### 填到服务器上

回到黑色窗口，**分两次**粘贴。

**① 填 Base URL**：先把下面这行里的"`你的BaseURL`"换成第 4 步复制的地址，再粘贴、回车：

```bash
sed -i 's|^LLM_BASE_URL=.*|LLM_BASE_URL=你的BaseURL|' /opt/xueqing/.env
```

**② 填 API Key**：粘贴下面这行，回车。看到"请粘贴 API Key"时，粘贴你的 Key，**只粘贴一次**，然后按回车。粘贴时屏幕上什么都不会显示，这是故意的：

```bash
read -s -p "请粘贴 API Key 后按回车: " K && sed -i "s|^LLM_API_KEY=.*|LLM_API_KEY=$K|" /opt/xueqing/.env && unset K && systemctl restart xueqing && echo " 已保存并重启"
```

**③ 测试连通**：粘贴下面这行，回车。几秒后出现"**连接成功**"就好了：

```bash
cd /opt/xueqing/backend && set -a && . /opt/xueqing/.env && set +a && /opt/xueqing/venv/bin/python -c "from openai import OpenAI;import os;c=OpenAI(base_url=os.environ['LLM_BASE_URL'],api_key=os.environ['LLM_API_KEY']);print(c.chat.completions.create(model=os.environ['LLM_TEXT_MODEL'],messages=[{'role':'user','content':'只回复四个字：连接成功'}]).choices[0].message.content)"; cd ~
```

如果出现一大段英文报错：
- 里面有 `401` 或 `InvalidApiKey`：Key 不对，重新做第 ② 步。
- 里面有 `404` 或 `model`：模型名不对，在百炼控制台的模型列表里确认模型名，然后告诉 AI 助手帮你改。

> 用其他服务商（比如 DeepSeek）也可以，只要它兼容 OpenAI 接口。把 Base URL 和 `.env` 里的两个模型名换成那家的就行，具体以对方的官方文档为准。注意：**要识别图片，必须选支持看图的模型。**

## 第 6 步：注册管理员，邀请老师

1. 打开 `http://你的公网IP`，点"免费开始"注册账号，邀请码填第 4 步记下来的那个。**第一个注册的账号自动成为管理员。**
2. 点左下角的**齿轮**进入设置：
   - "**新建报告默认信息**"里填好机构、校区、老师名，以后新建报告会自动填好。
   - "**管理员**"标签里可以更换邀请码、查看所有用户、重置别人的密码。
3. 把网址和邀请码私下发给要用的老师，他们自己注册就行。

## 建议顺手做的：设置花费提醒

阿里云不会自动帮你封顶花费，建议设置两个提醒：

- **高额消费预警**：费用与成本 → 成本监控 → 成本预警。产品选百炼，金额设为每天 5 元。
- **可用额度预警**：费用与成本 → 资金账户 → 可用额度预警。金额设为 20 元。

账户里只放少量余额，余额用完百炼就会自动停止调用，最多只会花掉这些钱。

## 常见问题

| 问题 | 怎么办 |
|---|---|
| 提示 `unzip: command not found` | 用上面那一整行命令，它会先运行 `apt-get update` |
| 粘贴命令后没反应 | 再按一下回车 |
| 浏览器打不开网站 | 检查第 2 步的 80 端口有没有加；确认用的是 `http://`，不是 `https://` |
| 看不到新功能 | 按 Ctrl+Shift+R（Mac 按 Cmd+Shift+R）强制刷新 |
| 网站出错了 | 在黑色窗口运行 `journalctl -u xueqing -n 40 --no-pager`，把输出截图发给 AI 助手 |
| 怎么升级到新版本 | 上传新的 `xueqing-release.zip`（覆盖旧的），然后运行 `cd /root && rm -rf xueqing && unzip -o xueqing-release.zip && cd xueqing && bash deploy/install.sh`。账号和报告都会保留 |
| 想用域名访问 | 国内服务器需要先做 ICP 备案，见 [DEPLOY.md](./DEPLOY.md#4-配域名和-https备案之后) |
